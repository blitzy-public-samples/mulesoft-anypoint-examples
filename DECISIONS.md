# Decision Log

This log covers the conversion of the 55 Mule 3 examples in this repository into standalone `<example>-java` Spring Boot projects. `sap-data-retrieval` is `EXCLUDED — pending sapjco3.jar`. Every non-trivial decision and every deviation from a literal reading of the request has a row. Rows D-001 … D-081 were set by the migration plan; rows from D-082 on record decisions taken while the projects were written. Rows are appended and never renumbered, and a row that supersedes or amends an earlier decision names that row.

Per-project status is in [SUMMARY.md](SUMMARY.md). The source-to-target mapping, whose Decision cells cite these IDs, is in [TRACEABILITY.md](TRACEABILITY.md).
